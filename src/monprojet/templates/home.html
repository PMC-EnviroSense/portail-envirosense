À propos du système EnviroSense

EnviroSense

Surveillance environnementale intelligente

EnviroSense est un système de stations environnementales permettant de collecter, transmettre et visualiser des données provenant de différents capteurs déployés sur le terrain.

Le portail permet de suivre l'état des stations, leur position ainsi que les données environnementales reçues.

Données collectées

Les stations peuvent recueillir différentes mesures environnementales :

  • Température de l'air
  • Humidité relative
  • Pression atmosphérique
  • Position géographique (latitude et longitude)
  • Autres capteurs selon les besoins

Transmission des données

Les stations utilisent différents moyens de communication afin d'acheminer leurs données.

LoRa Communication longue portée entre les stations déployées sur le terrain.
Wi-Fi Transmission des données vers l'infrastructure réseau lorsque la connexion est disponible.

Rôles des stations

Station de liaison

Assure la communication entre le réseau de stations et l'infrastructure de supervision.

Station de collecte

Collecte les mesures des capteurs et les transmet à travers le réseau.

Fonctionnement du système

1

Les capteurs effectuent les mesures environnementales.

2

La station de collecte prépare et transmet les données.

3

Les données sont acheminées vers la station de liaison.

4

Les informations sont enregistrées et affichées sur le portail EnviroSense.

État du système

Une station est considérée en ligne lorsqu'une communication récente a été reçue.

Après plus de 60 secondes sans nouvelle communication, elle est affichée hors ligne dans le portail.
